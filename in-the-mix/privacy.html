In the Mix

Privacy policy

Effective 11 October 2026

In the Mix is a private, single-user app run by Idle Machinery for the DJ Paranoid Androidz. It runs on one computer on a home network. It has one account, and only that account's owner can connect Google to it.

What it reads from Google

With the owner's consent, In the Mix gets read-only access to Google Calendar events (the calendar.events.owned.readonly scope, or calendar.readonly if that one turns out not to be enough). It reads event titles, times, locations, descriptions, colours and response status from the calendars the owner chooses. It never creates, changes or deletes anything in Google Calendar.

How it uses that data

  • To show the owner's upcoming DJ streams and gigs, and to keep a history of past ones.
  • To keep the owner's Twitch stream schedule in step: the titles and times of events the owner treats as streams are written to the owner's own Twitch channel schedule, which Twitch shows publicly. Nothing else from the calendar goes to Twitch.

The data is not sold, not used for advertising, not used to train AI models, and not shared with anyone else. There are no analytics or tracking.

Where it is kept

Calendar data is stored in a database on the owner's own computer, on their home network. The Google access token is stored encrypted on the same computer. Nothing is kept on a server elsewhere.

Removing access and deleting data

The owner can disconnect Google in In the Mix's settings, which deletes the stored token. Access can also be removed at any time from the Google account at myaccount.google.com/permissions. Deleting the app's database removes all stored calendar data.

Google API Services User Data Policy

In the Mix's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Changes and contact

If this policy changes, the new version is posted here with a new effective date. Questions can be raised on this site's GitHub issues.
